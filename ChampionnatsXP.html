Attaques Spéciales

Ces Pokémon attrapés ou évolués durant l'Évènement apprendront les Attaques suivantes (AI = Attaque Immédiate / AC = Attaque Chargée). Ces Attaques sont normalement Legacy et nécessitent une CT d'Élite pour pouvoir être apprises. Il s'agit généralement des anciennes Attaques des Community Days. Toutes ces Attaques sont bonnes pour la Ligue Go. En vert figurent celles qui sont aussi bonnes pour les Raids (Cf : Meilleurs Pokémon).

Stream

Vous pourrez regarder 4 streams différents pendant cet évènement pour obtenir des récompenses.

Voici la démarche à suivre pour profiter de ces récompenses :
1. Connectez-vous au Cercle des Dresseurs sur Pokémon Trainer Central
2. Associez votre compte Twitch sur ce même site (créez-en un si vous n'en avez pas)
3. Connectez-vous sur Twitch
4. Regardez la chaine mentionnée pendant le temps indiqué
◦ Vous pouvez vérifier votre avancement sur votre inventaire Twitch
5. Si vous avez regardé assez longtemps, retournez sur Pokémon Trainer Central et cliquez sur « Voir l'inventaire »
6. Copiez le code donné, puis allez sur la page des récompenses. Collez le code et cliquez sur « Appliquer »
7. Les bonus sont maintenant disponibles en jeu !
